# v4.4.0（试验先行版）— 素材架构换代、功能模块化与全局记忆

> **状态**：待发布。本版是 personal agent（4.5.0）与插件化之前的**最后一个稳定版**：
> 一批打底的大改动集中落地，经过全量测试与实机验收后放行。「试验先行版」指
> 功能模块化（设置 → 功能）是插件化的先行形态，默认配置对老用户完全无感。

## 为什么有这个版本

三件事凑在了一起：播放架构到了该换代的时候（每帧现场解码的 CPU 税一直在交）；
功能越加越多，设置页和右键菜单对大多数用户已经过载；AI 对话开始需要「记性」。
本版把这三件一次做完，外加一轮成体系的缺陷收口。

名字里带 `webm-chat` = 带 AI 对话；不带 `-chat` 的 `webm` 版是纯桌宠（没有对话功能）。

每一行后面的 sha256 是校验值，普通用户不用管。

## 一、素材与播放：无损帧序列

以前每播放一帧动画，后台 ffmpeg 就现场解一帧——24fps 的动画每秒就是 24 次解码，
整个播放期间这笔 CPU 税一直在交，多只宠还要叠加。

现在素材在后台一次性转成**无损帧序列**（逐帧无损 WebP，位精确验证过）：播放 =
内存取帧，CPU 接近归零，常驻的 ffmpeg 进程群整体退役。代价是多几十 MB 内存缓存
（有硬上限，不会无界涨）和一次性的磁盘转换——拿闲置内存换流畅，桌面应用这笔
交换是值的。短循环动画全走帧序列；长 clip 保留原视频路径（混合制）。

配套：**素材包市场**——角色素材可以按包下载/更新（重启生效），不用等整包升级。

## 二、功能模块化：设置里多了一个「功能」页

社区反馈了很久的问题：功能很多，但每个人用的就那么几个。现在 **设置 → 功能**
里可以勾选要启用哪些（天气、抽签、待办、音乐、AI 对话、语音、文件识别、主动识屏、
Agent 联动、灵动岛、快捷启动、直播捕获、跨屏等 16 个模块）：

- **没勾的功能不会出现菜单和设置，后台也不会运行**（重启生效）；
- **老用户升级：全部保持开启**，你的习惯一个不少；
- **全新安装：默认只开核心**（动画、互动、多宠、设置），想要哪个自己勾——
  第一次用不再被一屏功能吓住。

## 三、AI 对话：有记性了，也不卡了

- **全局记忆**：它会跨对话记住你的事。两种形成方式：你在对话里说「记住：……」
  或点气泡上的图钉（手动钉）；以及每 5 轮对话后它在后台**静默整理**值得长期
  记住的事（默认开，可在设置 → AI 与对话 → 记忆里关）。记忆按角色存在本机，
  设置里可查看、单条删、全部清空。
- **记忆分了层，也不再每轮硬塞进上下文**：偏好类（「记住偏好：……」）始终带着；
  事实、教训、话题三类只在**聊到相关话题**时才被捞出来（最多 3 条，同一个话题
  不重复捞），话题类 14 天没被提到会归档、需要时可恢复。实测典型注入量只有原来
  全量注入的三到四成——上下文省下来的位置留给真正的对话。
- **场景扮演（酒馆式，默认关）**：设置 → AI 与对话 → 场景扮演里可以填「场景卡」
  和「在场人物」，打开后它会用（动作）＋台词的方式演，场景切换给旁白、外人不再
  是应声虫、也不会替你写动作台词。动作段在气泡里显示成斜体弱色，存下来的原文
  一个字都不改。
- **聊天不再越聊越卡**：长会话改为分页加载，几百轮对话的窗口打开和滚动都顺了。
- **助手回复朗读**（默认关）：AI 回复可以念出来，与语音报时共用一条通道，不叠音。
- **修复**：Firefox 放歌现在也能被正确识别为浏览器（歌词/联动不再误判）。

## 四、成体系的修复收口

本版收口了一批缺陷，修掉的包括：

| 现象 | 根因与修法 |
|---|---|
| 设置改完点「保存并退出」弹保存失败（甚至崩溃） | 停用模块的行控件随旧页销毁，保存链撞上死控件；判活守卫 + 行持有防 GC |
| 设置页左上角莫名出现一个 Agent 按钮 | 模块停用后未挂载控件以 (0,0) 浮窗残留；域重建末尾统一隐藏（侧栏与页面堆栈显式排除） |
| 关掉 AI 模块的用户检查更新被发成纯桌宠安装包 | 更新器误把「功能开关」当「构建变体」；真值链分离 |
| 装 Qt 开发环境的机器上插件路径被污染（#323） | 启动链在任何 Qt 导入前消毒 QT_PLUGIN_PATH |
| 跨屏抛掷失效（#319，4.2.1 时期可以） | 抛掷边界恢复 legacy 语义 |
| macOS 输入法焦点被桌宠抢占 | 岛 raise 隔离 + 焦点策略修正 |
| macOS 多屏/切换 Spaces 后桌宠消失、设置进程出现第二个 Dock 图标 | 每屏一窗拓扑 + 原生 Spaces 策略 + Dock 策略集中（社区贡献） |
| 余额气泡「赠送 ¥2.3」「4）」被拆成两行 | 标签与金额之间加不换行连接（社区贡献 + 维护方补两个窄触发面回归） |
| 异高双屏时主屏正对副屏空洞的那条带过不去（主→副底部「有墙」） | 跨屏移动语义改为「过缝通行 + 落点吸附」：穿缝任意过（看不见是过渡态），松手/落地/落岛/弹弓取消四处收口吸附到最近的屏，任何静止都不落在看不见的地方 |
| 低速在屏幕边黏住一下又反弹回来 | 侧墙加水平速度截止（地板早有同款，侧墙漏了十年）：低速撞墙沿墙滑落 |
| AI 对话窗口关掉后内存不返还 | 聊天窗关闭即销毁（窗口树真正还给系统）；先证伪再修——探针证实是「缓存单例只隐藏」而非泄漏，quick_chat 才 31KB 有意保留缓存。同轮还修了 Esc 关窗漏收尾（开了「跟随桌宠」的用户会触发移动报错）与提示栏定时器回调死控件 |
| 「tick 间隔 p99=250ms」的疑似卡顿（#339） | 不是卡顿：250ms 是闲置降载档（T2）的刻意间隔，被误记进卡顿分位（CoarseTimer ±5% 正好解释了 235~265 的观测带）；现在只在满速档记账。体感掉帧若仍有，请带日志反馈 |

## 五、内部架构（用户无感，但值得知道）

- **聊天分页**（上面说过）之外，**10 个功能模块从平铺文件整理成目录包**——
  代码零行为变化，为的是以后修一个问题不再触一发而动全身，也是插件化的物理地基。
- 这批打底层动得深，所以放行前过了覆盖 9000+ 用例的全量测试与实机验收。

## 六、已知限制（如实）

- **从没保存过任何设置的老用户**（装了就没动过的）：升级后会被当成新装，拿到
  纯核心功能集——打开 设置 → 功能，点「全部开启」即可恢复，一次到位。
- **快速对话（气泡即问即答）会参与记忆整理，但不读记忆**——它是有意的轻量入口，
  完整记忆注入在正式聊天窗。
- **新装用户第一次打开设置**：功能页显示的就是纯核心勾选状态，不是「功能被吞了」。

## 七、升级说明

**配置不用动**：没有格式变更、没有键改名，旧配置直接能用。
**素材会在首次启动后自动转换**为帧序列（后台进行，转换期间动画照常走原路径，
无感）。**功能开关在 设置 → 功能**，重启生效。
